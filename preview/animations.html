dsh-thinking-quips — 全部动画与图标总览

本页不是插件的复刻：它原样运行 lib/client.js，并直接调用插件自己的 injectPluginCss() / ensureLoader() / applyStatusText() / apply()， 画在下面这些仿造的运行行上（标记形状与 DSH 一致，所以插件用的锚点是同一套）。 官方素材取自本机安装的 @deepseek-ai/dsh-client-ui-chat@0.2.0-rc.2 与 @deepseek-ai/dsh-client-ui-primitives@0.2.0-rc.2（构建时提取，非手工抄写）。
页面的 --dsw-* 颜色是近似值，只为脱离 app 也能出效果；真实观感以 DSH 界面为准。 设置行（React 组件）不在本页范围内，它需要 DSH 运行时。

1. 完整状态行（真实轮播）

这一行调用的是插件的 apply()：真的轮播俏皮话、真的用时、真的 600ms 重断言循环。 下面的控件改的是插件的真实配置（patchConfig），改完还会立刻触发一次插件的扫描， 所以点完马上见效（不必等它自己的 600ms 轮询）。 这一段必须排在所有仿造行之前：插件用 document.querySelector("[data-chat-running]") 找自己的行， 也就是文档里的第一个匹配。

2. 加载图标：9 种样式 × 3 种尺寸

每格都是对同一个仿造运行行调用一次 ensureLoader()。 DSH 自己的鲸鱼是"可选项之一"：只要插件画了自己的图标，就会给运行行打上 data-tq-icon，样式表据此把 DSH 那只收起来——所以屏幕上永远只有一个指示图标； 想要官方那只，就选 native。 native 走 cloneNode（格子里预置了 DSH 的鲸鱼节点）；最下面一行是 native 在没有鲸鱼节点时的 CSSOM mask 回退。stateDot 需要 DSH 的 React 组件， 本页提供不了种子，因此它会显示插件的兜底图标（圆环）——这正是老外壳上会发生的事。

3. 文字特效

每行调用一次 applyStatusText()。两种特效：wave 完全由插件自己画； shimmer 渲染 DSH 官方的 TextShimmer 组件 —— 本页没有 React 运行时，所以它给插件塞了 一个最小可用的替身（requireShim 里的 createElement / createRoot / TextShimmer），让插件的真实路径跑起来，画出组件自己的 DOM，再由原样内联的 TextShimmer.module.css 去动画化它。缺种子时插件仍会降级为纯文本（那才是真实的老外壳行为）。

开发者工具里 window.__tqPreview 就是插件的 __internal 接缝，可以直接调它的函数。
可用开发者工具检查这些行上的 data-tq-owned / data-tq-icon / data-style / data-effective / data-scale，它们就是插件在真实界面里写下的标记。 若浏览器禁止 file:// 页面使用 localStorage，控件改动不会生效——插件会退回出厂默认（轮播与图标仍然工作）。

4. 图标：设置分栏 + 插件列表

设置分栏图标是 DSH 按分栏 id 硬编码的（navIcon()，未知 id 一律回落到 齿轮），第三方分栏没有图标入口 —— 所以插件给自己的导航行打标记、再用 CSS mask 画上官方那只鲸鱼； 下面把官方齿轮、官方「内置插件」图标与插件导航图标并排（16px + 8× 放大，都是它在这页上的真实观感）。

插件列表图标（设置 → 内置插件里每一行的图标）走的是另一条路：package.json 的顶层 icon 字段，Host 读成 data URI 喂给页面，尺寸不限但周边样式由清单提供 —— 所以图标自己要是 36×36、透明底、圆角、柔和渐变。locale/<语言>.json 提供那一行的标题与描述 （必须被 exports 暴露，否则会回落成包名 —— 这行以前就是那样）。

5. 官方扫光的亮度

这一节是 DSH 官方 TextShimmer 的真实 DOM 结构与真实样式表 （TextShimmer.module.css 在构建时从 primitives 原样内联，用 @scope 限定在本节内，没有改写任何选择器）。 它的高光就是 .sweep{ color: var(--dsw-alias-label-shimmer) } 加上一道移动的渐变遮罩 —— 所以设置里的「扫光亮度」改的正是这个 token（把文字色往白里混）：0% 时高光与文字同色（看不出扫光）， 100% 时纯白。拖动上面的亮度框，下面的高光会跟着变。
