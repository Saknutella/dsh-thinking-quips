# Loading 图标设计需求(简报)

> **用途**:为 `dsh-thinking-quips` 插件新增"运行中(loading)"图标样式时,把这份简报发给设计方或协作者。
> **刻意不含实现细节**:不出现 DSH 类名、插件内部字段或代码约定,只讲"要什么样的动画图标"和"怎么算合格"。
> **相关文档**:[交接手册](交接手册.md) 记录了插件侧的实现契约;这里是**设计侧**的需求。

---

## 使用场景

它出现在界面里一行"正在处理…"这类文字旁边(或按钮里、列表行里),尺寸很小 —— 大约 **14–20 像素见方**,
会持续几秒到几十秒,而且会被用户**反复看到**。所以它不是装饰画,是**一个每秒都被盯着看的小动画**。

---

## 硬要求

### 1. 绝对不能写死尺寸 —— 必须和正文字号同步缩放(最重要,不满足直接不合格)

- 图标大小要**绑定旁边文字的字号**:界面字号从 14px 调到 22px,图标必须**跟着等比变大变小**,
  而不是"按 16px 画好、到处固定显示 16px"。
- 描述形状时请用**相对比例**,不要用绝对像素:说"直径 ≈ 1 个字高""笔画 ≈ 1/16 个字高""两元素间距 ≈ 1/8 个字高",
  **不要**说"16px 的圆、2px 的间距、1px 的线"。
- **笔画粗细也必须一起缩放**:字号变大时笔画相应变粗,否则会出现"大字号配一根发丝线"的露馅效果。
- 图标占位的盒子同样由字号决定(例如"1 个字高见方"),不能是固定盒子 —— 否则图标与文字的大小关系被锁死。
- **自查**:把字号在 14px 与 22px 之间来回改,图标应当**整体缩放且比例不变**。
  任何人交来的 SVG 里只要出现**写死的 px 宽高**,就是不合格。

### 2. 一眼看懂

在 16px 的原始尺寸下(不要放大看),**0.3 秒内**能看出"有东西在忙";不能是静止图形加一点闪。

### 3. 为小尺寸而画

在 16px 下笔画至少 1px 可见;小于 2px 的结构一律不要;多个元素之间至少留 1–2px 空隙,否则糊成一团。

### 4. 一种颜色

颜色由外部主题/文字颜色决定,图形是**单色剪影或单色描边**;不做渐变、不用两种以上明暗;浅色底和深色底都要成立。

### 5. 矢量,不要位图

不接受像素画、图片序列帧、GIF —— 它们在不同屏幕上要么糊,要么得为每种尺寸准备一份素材。
(想要"像素风"可以,但要用**矢量方块**画,不要贴位图。)

### 6. 无限循环、首尾无缝

循环 0.8–3 秒;循环接点**不能"跳一下"**;节奏要有呼吸感,不要抽搐式急停急动。

### 7. 动作要有性格,但别撒谎

- 可以俏皮:拧螺丝、钓鱼、蜗牛爬坡、打蛋、小火车、翻书、吹泡泡…;
- **不要暗示"快完成了"**(进度圈越走越满然后重置,会让人以为卡住),也不要暗示出错;
- 闪动不超过**每秒 3 次**(光敏安全)。

### 8. 克制

动作幅度小,不抢旁边文字的注意力;整体像"一个小小的、有生命的等待者"。

### 9. 适配"减少动态效果"

系统要求减少动效时,它能停在一个**本身也读得通**的静止帧上。

### 10. 实现友好

只用位移/旋转/缩放/透明度这类动画;不要画布、不要 JS 每帧计算;图标占据的盒子固定,
出现与消失不能让周围文字抖动。

## 可选:风格方向

**如果我有指定风格,请严格按该风格设计;如果没有指定,请自己选一个并在交付里说明理由。**
无论选哪种,**都不能破坏上面第 1、4、5 条**(尤其是"单色 + 随字号缩放 + 矢量")。

可以指定的风格举例(括号里是"在这个尺寸下要小心什么"):

| 风格 | 特征 | 小尺寸注意 |
| --- | --- | --- |
| **包豪斯(Bauhaus)** | 基本几何形(圆/方/三角)+ 三原色逻辑,去装饰 | 只用**一种**颜色;靠形状与位置区分元素 |
| **瑞士/国际主义** | 网格、留白、像交通标识一样精确 | 网格间距要按字号比例,网格太密会糊 |
| **任天堂式(游戏机手感)** | 圆润、有弹性,夸张的挤压与拉伸(squash & stretch) | 挤压幅度控制在 1–2px 量级,过大就"抖" |
| **矢量像素风** | 方块、整数格、8-bit 观感 | **必须用矢量方块画**,不要位图;格数控制在 10–16 格 |
| **极简描边** | 统一 1 格粗细的开口线条 | 描边与留白比例固定,才能随字号缩放不失衡 |
| **手绘涂鸦** | 线条略抖,像随手画 | 抖动幅度按比例给,别固定像素 |
| **复古霓虹** | 高对比、有"发光"错觉 | 只用一种颜色,靠粗细/透明度做层次,不靠渐变 |
| **剪纸/层叠** | 剪影分层,像纸上剪出来再叠起来 | 层次靠**空隙**而不是明暗,因为只有一种颜色 |

## 交付格式

每个图标给我:

1. **名字**;
2. **一句话比喻**(它在干什么);
3. **什么在动、往哪个方向动**;
4. **关键帧与时长**(例:"0→40% 抬起并缩小,40→70% 落下,70→100% 静止");
5. **尺寸与笔画如何随字号表达**(按第 1 条,用相对比例说明);
6. 它在 **16px** 下的观感一句话;
7. **最容易做坏的地方**。

有草图更好:**单色 SVG、透明底**,形状用相对比例标注即可,实现交给我。

请给我 **6–10 个**,最好形成一个**风格家族**(笔画粗细、节奏规律一致),这样它们可以作为"几种可选样式"同时存在。

## 校准用例子(可选参考,可直接删掉)

| 名字 | 比喻 | 什么在动 | 为什么小尺寸可行 |
| --- | --- | --- | --- |
| 蜗牛赶路 | 一只蜗牛努力往前爬 | 身体前后轻微伸缩,身后留下一串小点(到尽头时首尾相接) | 只有"壳 + 尾"两个形状,运动是水平位移 |
| 钓鱼浮标 | 浮标一沉一浮 | 浮标上下动约 1/16 个字高,水面两圈涟漪扩散淡出 | 涟漪就是两个同心小圆弧 |
| 拧螺丝 | 螺丝被一下下拧紧 | 十字槽每次转 90° | 纯旋转不改变外形,最安全 |
| 小火车 | 小火车在轨道上跑 | 车头前进,烟囱冒两朵小烟向上散开 | 车头是一个圆角块,烟是 1/16 字高的小方块 |
| 翻书 | 书页翻过去又翻回来 | 一页纸掀起、翻面、落回 | 轮廓始终是直线,变化只是梯形角 |
| 编织 | 两股绳绞在一起 | 两条波浪线相位交错推进 | 两条 1/16 字高粗细的曲线,相位差 180° |
| 吹泡泡 | 泡泡从管口升起破掉 | 小圆上升 + 变大,顶端淡出,下一个接上 | 只有"圆 + 透明度"两个维度 |
| 小鲸鱼喷水 | 鲸鱼浮出水面喷一下 | 身体几乎不动,3 颗水滴从头顶升起、散开、落下 | **必须矢量画**;水滴要撑得住 16px |

## 验收(我会逐条实测)

1. 14–20px 的 1:1 尺寸下,不解释也能看出是什么;
2. 浅色底与深色底都成立;
3. **字号从 14px 改到 22px,图标跟着等比缩放**且不变形;
4. 系统开启"减少动态效果"时停止,且停帧仍读得通;
5. 循环接点无跳动;
6. 插件自带的 14 套自检与 `check` / `doctor` / `hygiene` 全绿;
7. 同步更新设置项标签、交接文档、README/ROADMAP,并重新生成离线动画总览页。
