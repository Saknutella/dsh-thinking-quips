# 0.2 适配与合并方案(实施前调研 → 已实施)

本文件是**这个插件专属的研发记录**:`dsh-thinking-quips` 在 DSH **0.2.0-rc.2** 上的适配
与"与官方合并"方案。所有事实均实测于本机(测量时间 2026-09-30);§10 是已实施清单。
前置阅读:[05 运行状态行变更](../../../docs/05-DSH-0.2-运行状态行变更.md)(锚点漂移 + shimmer 换实现)、
[状态行扩展调研](状态行扩展调研.md)(素材动态引用 + 用时可行性)。

---

## 0. 一页结论

1. **旧 quip 能完整保活**,需要 **3 处移植 + 2 处删除 + 1 处新增固件**(清单见 §2)。
2. **官方可复用面比 0.1.x 大得多**:0.2 的平台种子是 **9 个**,其中
   `@deepseek-ai/dsh-client-ui-primitives` **就是官方组件库**(`TextShimmer`、`StateDot`、
   `FishLogo`/`FISH_LOGO_PATH`、`SettingsForm`、`Switch`、`SegmentedControl` …),
   `@deepseek-ai/dsh-client-store`、`@deepseek-ai/dsh-client-ui-slots` 也在种子里
   —— 插件可以**直接 `require`,不用写进 `dsh.client.external`**(§1.1)。
3. **官方没有"运行状态行"的插槽**(§1.5),所以状态行上的图标与文字只能由插件自己渲染;
   官方的鲸鱼素材可以零拷贝引用(07 §1),官方图标组件可以直接 import。
4. **但"用时"有官方座位**:`conversation.chat.turnTail`(list / session 作用域)在
   **回合进行中就会挂载**,props 直接给 `turn: TurnLocation`(含 `start.time` / `status`)
   —— 比 DOM 里抠文本干净得多(§4)。
5. 需要你拍板 **5 项**(§7);工作区工具有 **1 处过期**必须同步(§8)。

## 1. 官方可复用面(实测)

### 1.1 平台种子:0.2 的 9 个可 `require` 名字

实测自 `dsh-web-frontend/dist/assets/index-*.js` 的静态模块表(`rM()`):

```js
{ "react":…, "react/jsx-runtime":…, "react-dom":…, "react-dom/client":…,
  "@deepseek-ai/cordis":…, "@deepseek-ai/dsh-client-store":…,
  "@deepseek-ai/dsh-client-ui-slots":…, "@deepseek-ai/dsh-client-ui-primitives":…,
  "@deepseek-ai/dsh-client-ui-dockkit":… }
```

含义:这 9 个是**平台种子**,客户端插件 `require` 它们不需要 `dsh.client.external`,
`dsh-client-modules` 的 `makeRequire` 会直接命中 `seed` 表。本工作区工具里记的种子仍是
0.1.x 时代的 5 个(且 `cordis` 名字不对,见 §6),所以"复用官方代码"这条在 0.2 上才是新能力。

### 1.2 `dsh-client-ui-primitives` 的导出(按插件功能位归类)

| 插件功能位 | 可直接复用的官方导出 |
| --- | --- |
| 状态文字扫光 | **`TextShimmer`**(新实现,见 05 §8) |
| 加载图标 | **`StateDot`**(`state: "ongoing"` = 官方 14px 转圈,自带 reduced-motion 降级)、**`FishLogo` / `FISH_LOGO_PATH` / `FISH_LOGO_VIEWBOX`**(官方鱼形剪影,d.ts 明说"exported for consumers that compose their own svg") |
| 设置行 UI | `SettingsForm`、`SettingsValueField`、`SettingsSecretField`、`Switch`、`SegmentedControl`、`SegmentedTabs`、`Button`、`Pill`、`Tag`、`Input`、`Checkbox`、`Tooltip`、`HoverCard`、`Menu*` |
| 提示/弹窗 | `Modal`、`Toast`、`Tooltip`、`RiskConfirmation` |
| 其它 | `PathLabel`、`ShortcutKeys`、`ConnectionIndicator`、`FileTypeIcon`、`LinkIcon`、`ReferenceIcon`、`PermissionIcon*`、`BrandWordmark`、`fileSizeText`、`writeClipboard` |

插件现在手写的 `.tq-switch` / `.tq-seg` / `.tq-modal` 等都能换成官方组件(观感统一、少维护),
但属于"可选升级",不影响保活。

### 1.3 官方动画 / 图标资产清单

| 资产 | 在哪 | 复用方式 | 适合做加载图标? |
| --- | --- | --- | --- |
| 鲸鱼尾巴(APNG 60 帧 + 静态 SVG 回退) | chat bundle 里的内联 CSS/JS(**不是种子**) | CSSOM 扫 data URI,或 `cloneNode(true)`(07 §1.2/1.3) | ✅ 推荐作"原生"选项 |
| `StateDot state="ongoing"` | primitives(种子) | `require(...).StateDot` 直接渲染 | ✅ 现成转圈 |
| `FishLogo` / `FISH_LOGO_PATH` | primitives(种子) | 直接渲染,或取 path 自组 SVG | ✅ 静态鱼形 |
| `ConnectionIndicator` 的 3 点 | primitives(种子) | 是带文案的按钮,不是裸图标 | ❌ |
| `dsh-turn-mark-busy`(轨道忙碌脉冲 1s) | chat 本地 keyframes | 绑在回合导航轨道上 | ❌ |

### 1.4 官方颜色 / 文案 / 结构钩子(0.2 新增)

- **token**:`--dsw-alias-label-deep-diving`、`--dsw-alias-label-deep-diving-shimmer`、
  `--dsw-alias-label-shimmer`(运行行会把后者重映射为 deep-diving 专用那个,见 05 §8)
- **文案**:`chat.deepDiving`(隐藏播报)、`chat.deepDivingFor`(可见,含用时)、
  `duration.hourUnit / minuteUnit / secondUnit`、`duration.compactSeconds / compactMinutes`
- **结构**:`[data-chat-running]`、`[class*="runningContent"]`、`[class*="runningText"]`、
  `[class*="runningIcon"]`、`[data-shimmer]`、`data-shimmer-text`
- **服务**:`ctx.uiConversation.binding(id).openTurn` / `.target("chat").legacy.turnTimings`;
  `ctx.sessions`;`ctx.uiSession.sessionStatus`(见 07 §2.2 路线 C)

### 1.5 官方插槽:**没有**运行状态行的座位

根 `docs/slots.generated.md` 里与"运行中"沾边的只有三条,都不是状态行:

| 插槽 | kind / scope | 说明 | 能不能用 |
| --- | --- | --- | --- |
| `shell.overlay` | list / root | 全框浮层,"badge / toast / status pill 都放这",点击穿透 | ⭕ 官方认可的"整框活动提示"座位(但不是行内状态行) |
| `conversation.chat.turnTail` | list / **session** | 回合尾部特性位,props `{ turn: TurnLocation, seq, openFile }`;**`closing === null`(回合进行中)也会挂载** | ✅ **用时的官方座位** |
| `conversation.chat.assistant-actions` | list / session | 已经定稿的助手消息动作位 | ❌ 事后 |

结论:**状态行(图标 + 文字)没有官方座位**,合并只能在插件自己渲染的 DOM 里做;
而"用时/回合级信息"有官方座位,应该优先用它。

## 3. 合并点 A:图标

- **位置**:`.runningContent` 内、官方 `[class*="runningIcon"]`(鲸鱼)所在之处。
- **两种关系**(需拍板):
  - **互斥**:插件启用时把官方 icon 藏起来(`[class*="runningIcon"]{display:none}`),视觉最干净;
  - **共存**:官方鲸鱼 + 插件图标并排,`indicatorOnly` 语义更自然,但会出现两个"活动指示"。
- **新增图标选项**(建议合并进现有 6 种之后):
  - `native` —— 官方鲸鱼,零拷贝(CSSOM 扫描 / cloneNode),拿不到时 fail-soft 回退;
  - `stateDot` —— `require("@deepseek-ai/dsh-client-ui-primitives").StateDot`(`state="ongoing"`,size 16);
  - `fish` —— 官方 `FISH_LOGO_PATH` 自组 SVG(可加旋转/淡入)。
- **官方观感优先**:既然官方已经有"整体活动指示"的语言(鲸鱼、StateDot),插件的自绘图标
  在风格上应让位;`native` 建议做默认。

## 4. 合并点 B:用时(推荐走官方座位)

**官方座位(首选)**:`conversation.chat.turnTail`(list / session)

```js
ctx.slots.inject("conversation.chat.turnTail", () => ctx.slots.register({
  name: "conversation.chat.turnTail",
  id: "thinking-quips-clock",
  locale: DICT_NS,
  inject: () => ({}),
}, TurnClockRow));   // props: { turn: TurnLocation, seq, openFile, …session props, t }
```

实测依据(`dsh-client-ui-chat/lib/client.js` 的 `TurnTailNodeView`):

```js
const tail = renderSlot("conversation.chat.turnTail", { turn, seq: closing?.finalNode.seq ?? data.seq, openFile });
if (closing === null) return tail === null ? null : <div data-turn-tail={data.turn}>{tail}</div>;
```

`closing === null` 正是**回合进行中**,所以这个座位在跑的时候就在;`TurnLocation` 带
`start: SessionEvent<'turn/start' | undefined>`(其 `.time` 就是权威起始时刻)、`status: 'open'|'closed'|'unknown'`、
`end`、`steps`。于是用时功能:

- **不需要**服务链、不需要拿当前 sessionId(座位本身是 session 作用域,props 直接给 turn);
- 格式化照 07 §2.1 的实现(与官方 `formatRunDuration` 对拍 **0/13 差异**);
- 每秒 tick 用 `useEffect` + `setInterval` 或官方 `@deepseek-ai/dsh-client-store`。

**备选**:状态行内自渲染(需要自己起 tick + 一次标签校准,见 07 §2.2 路线 A/B)。
**注意**:官方状态行本身仍显示它自己的用时,所以"运行行内再显示一次"会重复;走 turnTail 不重复。

## 5. 合并点 C:shimmer

| 选项 | 做法 | 观感 | 建议 |
| --- | --- | --- | --- |
| `shimmer`(现状默认) | 不碰官方,官方行自己扫 | 0.2 新版(阶梯 + token 着色) | 保留默认 |
| `official` | 自己节点外包官方 `TextShimmer`(种子导出) | 与官方完全一致,且能嵌进插件布局 | 推荐新增 |
| `glow` | 自研 `background-clip:text` 渐变(05 §8.1 那 6 行) | 0.1.x 旧版"文字自身闪光" | 你已表示可保留 → 由你拍板 |

三者都不再依赖 DSH 内部元素结构(只依赖一个种子 import 或纯 CSS)。

## 6. 工作区工具需要同步(否则会误导下一个人)

`tools/lib/util.mjs` 的 `PLATFORM_SEEDS` 是 0.1.x 的 5 个:**4 个缺失 + 1 个名字错**:

```
现在:react, react/jsx-runtime, react-dom, react-dom/client, cordis
应为:react, react/jsx-runtime, react-dom, react-dom/client,
     @deepseek-ai/cordis, @deepseek-ai/dsh-client-store,
     @deepseek-ai/dsh-client-ui-slots, @deepseek-ai/dsh-client-ui-primitives,
     @deepseek-ai/dsh-client-ui-dockkit
```

- 后果 1:插件一旦 `require("@deepseek-ai/dsh-client-ui-primitives")`,会被 `npm run check`
  当成"未声明模块"报 **warn**(不是 fail,`check.mjs:246`),误导人往 `external` 里写;
- 后果 2:`require("cordis")` 会被当合法种子,但浏览器里真正的名字是 `@deepseek-ai/cordis`。

另外 AGENTS §6 的两模式要求,插件现在只有 webui 侧行为,新函数要照 `templates/dsh-plugin`
补断言。

## 7. 需要你拍板的 5 个决定点

1. **载体**:改参照插件 `plugins/deepseek_thinking_quip/`(AGENTS 默认不改,需你明确授权),
   还是 `npm run new -- <name>` 新建插件?
2. **图标默认**:`native`(官方鲸鱼)/ `stateDot` / 保持 `orbit`;官方 icon 与插件图标**互斥还是共存**?
3. **textEffect**:是否新增 `official`(官方 `TextShimmer` 包插件自己的字)与 `glow`(复刻 0.1.x 观感)?
4. **用时位置**:官方 `conversation.chat.turnTail` / 状态行内自渲染 / 两者都要(会重复,不建议)?
5. **速度**:是否继续尝试缩放官方 shimmer(建议:**不**,0.2 里要打 `.sweep`/`.highlight`,且 0.6.1 已明确"官方扫光保持自己的节奏")?
