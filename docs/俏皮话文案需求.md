# 俏皮话文案需求(简报)

> **用途**:给 `dsh-thinking-quips` 扩充默认俏皮话时,把这份发给写手或协作者。
> **相关文档**:[交接手册](交接手册.md)(实现契约)、[loading图标设计需求](loading图标设计需求.md)(图标侧简报)、[插件文档索引](README.md)。

---

## 它出现在哪里

它替代 DSH 状态行里那句默认的"深度求索中 / Deep diving…",出现在对话中"Agent 正在干活"的那一行上。
颜色与特效跟随用户设置(官方扫光,或文字波浪),**后面可能紧跟"，用时 12秒"**;每条默认显示 8 秒
(用户可在设置里改成 1–120 秒),**按独立时钟轮转**,不随界面重绘而跳回第一条。

## 一、形式(技术边界,不满足就用不了)

1. **一行一条**:不能有换行(设置里是逐行文本,一行 = 一条);
   也不能出现**双引号** `"` 或反斜杠 —— 它会作为 JS 字符串字面量写进代码。
2. **成对交付**:每条尽量给**中英各一版**,但**不要直译**,两种语言各自说人话。
3. **短**:中文 **≤ 14 字**、英文 **≤ 45 字符**。状态行会折行,长句会把那一行撑成两三行。
4. **结尾要能接时长**:默认开着"用时"内联显示,文案后面会紧跟"，用时 12秒" ——
   所以中文以 `…` 收尾、英文以 `...` 收尾(与现有条目一致),不要用句号或完整句收束。
5. **不要 emoji**:跨平台渲染不一致,文字波浪效果对它的切分也不确定。

## 二、语气与内容

6. **暗示"正在做某件事",绝不暗示"快完成了"或"出错了"** —— 后者会让用户以为卡住或失败。
7. **有画面感、有个性**,读起来像同一个"嘴碎的资深工程师/手艺人"在自言自语;不要三句都是"正在思考"。
8. **语言各自的本土味道**:
   - 中文:可以是"正在 X…"句式,玩职场黑话、家务、手艺、江湖;
   - 英文:现在分词或名词短语的隐喻,计算机诗性、英式冷幽默都可以,但**别是中文的翻译腔**。
9. **避开**:政治 / 宗教 / 成人内容、真人姓名、商标、"网络烂梗"(半年后就过时的)、
   任何可能被误读成系统提示的句子。
10. **风味可以有层次**(加分项):车间手工 / 侦探档案 / 厨房 / 航海钓鱼 / 宇宙科学 / 田园 /
    办公室黑话 / 游戏机 —— 每层给几条,整批读起来像一个人的多个侧面。

## 三、数量与交付

11. 目标 **20–40 对**(中英合计 40–80 条)。现有默认是 **9 中 + 9 英 = 18 条**,
    8 秒/条 → 一轮约 2.4 分钟;加到 40 条即 5 分钟以上才重复,体感明显更好。
12. 交付格式:一个文本块,我直接贴进默认列表 ——

```
# Chinese
正在给思路拧上最后一颗螺丝…
正在把散落的点连成线…
# English
Tightening the last screw on this idea...
Connecting the dots that keep rolling away...
```

13. **保留还是替换**:现有 18 条建议保留(它们是风格基准);要替换请指明删哪几条。
    新增的会同步更新设置页说明与自检里的相关断言。

## 验收(我会逐条过)

1. 逐条机械检查:长度上限、无换行、无双引号/反斜杠、结尾是 `…` / `...`;
2. 用插件自己的解析器跑一遍,确认 `# Chinese` / `# English` 分段被正确识别;
3. **三种语言模式**(混合 / 仅中文 / 仅英文 / 跟随界面)都不出现空段或缺内容;
4. 设置页照常显示与编辑,新增条目可被用户覆盖;
5. 门禁全绿:插件 14 个自检套件 + `check` + `doctor` + `hygiene --strict`;
6. 重新生成预览页并目测轮播效果(含"用时"内联显示的那种组合)。
