## 2. 功能清单:每个功能的落点与配置键

配置键全部在 `lib/client.js` 的 `DEFAULTS`(第 290 行):

```js
const DEFAULTS = { enabled: true, color: SHIMMER, colorTheme: false, langMode: "ui",
  quips: DEFAULT_QUIPS, perLang: {}, quipMs: 8000, glow: 35, indicatorOnly: false,
  loader: "orbit", loaderSize: "md", textEffect: "shimmer", speed: "normal",
  clockMode: "inline" };
```

| 功能 | 配置键 | 取值 | 实现落点 |
| --- | --- | --- | --- |
| 俏皮话列表 | `quips` / `perLang` / `langMode` | `"ui" \| "en" \| "zh" \| "mix"` | `parseQuips` / `selectPhrases` / `QuipsModal` |
| 每条显示时间 | `quipMs` | 1000–120000 | `pass()` 的轮播下标 |
| 加载图标 | `loader` | `orbit/ring/pulse/dots/bars/morph` | `ensureLoader`(1352)、`ensureRing`、`ensureMorph` |
| 图标尺寸 | `loaderSize` | `sm/md/lg` | `LOADER_SCALES` + `--tq-loader-scale` |
| 文字特效 | `textEffect` | `shimmer/official/wave/glow` | `applyStatusText`(1139) |
| 用时显示 | `clockMode` | `off/inline/separate` | `pass()` + `withInlineClock`(821)/`renderClock`(1212) |
| 字体颜色 | `color` / `glow` | `"shimmer"` 哨兵 或 `#rrggbb`;glow 0–100 | `applyColorCSS`(1485)、`paintHost` |
| 匹配/跟随主题 | `colorTheme` | `true/false` | `matchThemeColor` + 主题观察器 |
| 动画速度 | `speed` | `slow/normal/fast` | `applySpeedCSS`(1548)+ CSS 里的 `var(--tq-speed)` |
| 只显示图标 | `indicatorOnly` | `true/false` | `pass()` → `releaseOwnership` |

**注入的 ctx 服务**:`inject = ["slots", "locale"]`;**注册的插槽**:`settings.general.item`(设置行,id `thinking-quips`,order 40)与 `conversation.chat.turnTail`(用时桥,id `thinking-quips-clock`)。**样式元素 id**:`dsh-thinking-quips-style`(插件 CSS)、`-color`、`-speed`。

### 3.3 官方颜色 token(0.2 新增)

| token | 用途 |
| --- | --- |
| `--dsw-alias-label-deep-diving` | 运行行文字色(light `deepseek-500 70% + blue-950`,dark `deepseek-450 55% + neutral-bluish-400`) |
| `--dsw-alias-label-deep-diving-shimmer` | 运行行扫光带的颜色;`.EvIC1a_running` 把 `--dsw-alias-label-shimmer` 重映射到它 |
| `--dsw-alias-label-shimmer` | 通用扫光带色(浅色 `neutral-1000 30% transparent` / 深色 `neutral-00 45% transparent`) |

插件就是把 `--dsw-alias-label-shimmer` 设在运行行上实现自定义扫光色(见 `paintHost`)。

### 3.4 用时:`conversation.chat.turnTail` 座位 + 官方格式化

- 座位:`conversation.chat.turnTail`(list / **session** 作用域),props `{ turn: TurnLocation, seq, openFile }`;
  `TurnTailNodeView` 在 `closing === null`(**回合进行中**)就会挂载它 → 这是官方给的"回合时间"来源。
- `TurnLocation = { turn, start?: SessionEvent<'turn/start'>, end?, status: 'open'|'closed'|'unknown', steps, data }`
  → `turn.start.time` 就是权威起始时刻(DSH 自己的时钟用的同一个字段)。
- 格式化(从 bundle 取出的官方实现):`floor(ms/1000)` → 时/分/秒;`hours>0` 才输出小时;`total>=60` 输出分钟;
  单位 i18n key `duration.hourUnit/minuteUnit/secondUnit`,zh `小时/分/秒`,**en `"h "`/`"m "`/`"s"`(带尾随空格)**。
  插件的 `formatDuration` 与官方对拍 13 组**零差异**,并有断言(见 `test/test-adapt-02.mjs`)。

复查:`Select-String -Path <chat bundle> -Pattern 'conversation.chat.turnTail|dsh-row-shimmer-sweep|turnTimings'`

### 3.5 扫光换了实现(0.1.x vs 0.2)

0.1.x 是"文字自身 `background-clip:text` + 250% 渐变滑 `background-position`";
0.2 是"真实文本 + `aria-hidden inert` 装饰层,`mask-image` + `translateX` 双向平移,`steps(48,end)` + 0.3s 首轮延迟"。
完整对照与工程评价见 [05 §8](../../../docs/05-DSH-0.2-运行状态行变更.md)。

## 4. 适配设计:为什么这么做

| 问题 | 选择 | 理由 / 代价 |
| --- | --- | --- |
| 锚点 | `[data-chat-running]` 属性优先,旧 `[class*="turnStatus"]` 兜底 | 属性是 0.2 里唯一不随 CSS Module 哈希变的东西;兜底保住 0.1 外壳与旧自检 |
| 那个 `role="status"` span | **永不写入** | 它是 1px 裁切的屏幕阅读器播报;旧代码的文本兜底正是写进它 → 插件"看起来没反应"的元凶 |
| 怎么拿可见行 | 官方标签用 `data-tq-owned` 属性**隐藏**,插件自建 `.tq-line` | React 每秒重写那个标签(带用时),清空它下一秒就被恢复;装饰副本还会用 `data-shimmer-text` 复现旧文本 |
| `shimmer` 与 `official` | 同一实现:渲染官方 `TextShimmer`(种子 + 小 React root) | 0.2 里"官方扫光"只存在于那个组件里,不可能在宿主元素上复现;保留 `shimmer` 这个名字是为了兼容已存的配置 |
| `glow` | 插件自有节点上的 `background-clip:text` 渐变 | 复刻 0.1.x 观感;因为是自己的节点,不再依赖 DSH 内部 |
| 缺种子时 | `official`/`shimmer` 回退到 `glow`(不抛错) | 老外壳没有这个种子;fail-soft 是硬要求 |
| 颜色 | 改设 `--dsw-alias-label-shimmer` + 自有 `--tq-base/--tq-hi` | 0.2 的扫光既不在宿主元素、也不是 `background-image`,旧的渐变手术无处可施 |
| 速度 | 只缩放插件自己的动画(`--tq-speed`) | 官方扫光的动画在 `.sweep`/`.highlight` 上,属于别人的组件(用户决定不缩放) |
| 官方图标 | **共存**:插件图标追加进 `runningContent`,鲸鱼不动 | 用户决定;视觉顺序 = 官方鲸鱼 → 插件图标 → 文字 |
| 用时来源 | 官方 `turnTail` 座位 → `officialTurn`;座位不在时自计时 | 走官方拿权威起点,不需要服务链也不需要知道是哪个会话;自计时兜住老外壳 |

## 9. 决策记录(用户拍板)与升级须知

| # | 决定 |
| --- | --- |
| 1 | **授权修改 `plugins/deepseek_thinking_quip/`**(默认约定是"参照插件不改") |
| 2 | 官方图标与插件图标**共存**,不隐藏 DSH 的鲸鱼 |
| 3 | 文字特效**新增 `official` 与 `glow`**(`shimmer` 保留为默认/别名) |
| 4 | 用时**两种位置可选**:`inline`(并进文字一起动画 = 0.2 形式)/ `separate`(灰色小字、不参与动画 = 0.1 形式),并可关;时间源尽量复用官方 |

**从 0.6.2 升到 0.7.0 的行为差异(用户可见)**:

- 状态行**默认带上"用时 N秒"**(`clockMode: "inline"`);想干净就选「关闭」。
- `shimmer` 现在由插件渲染官方 `TextShimmer`,观感与 0.2 官方一致;0.1.x 的旧观感用 `glow`。
- 速度档位**不再影响官方扫光**。
- 安装要求从 `>=0.1.2-rc.1` 提到 `>=0.2.0-rc.2`(仍兼容 0.1.x 外壳的锚点)。
