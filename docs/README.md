# dsh-thinking-quips — 插件自己的文档

本目录几份都是这个插件专属的记录(其中两份是**给外部协作者的简报**:图标设计 / 俏皮话文案)。

| --- | --- |
| [交接手册](交接手册.md) | **接手研发第一份就读它**:环境与路径、DSH 0.2 契约(附复查命令)、代码地图、门禁、待办优先级、决策记录 |
| [图标素材库（两支家族）](../.sprites/loading-icons/README.md) | **要改图标本身或再加一个时**：14 个候选的规范、每个的比喻/动作/关键帧、两支家族的验收清单；`svg-final/` 是入选的 8 个交付件 |
| [loading图标设计需求](loading图标设计需求.md) | **要新增 loading 图标样式时,先把这份发给设计方**:刻意不含实现细节的设计简报(必须随字号缩放、单色、矢量、循环无缝、可选风格方向、交付格式、验收标准) |
| [俏皮话文案需求](俏皮话文案需求.md) | **要扩充默认俏皮话时,把这份发给写手**:形式硬边界(一行一条、成对中英、长度上限、结尾要能接"用时")、语气禁忌、数量与交付格式、现有 18 条风格基准 |
| [0.2适配与合并方案](0.2适配与合并方案.md) | 想知道"为什么这么适配"、官方可复用面清单、三个合并点、§10 已实施清单 |
| [状态行扩展调研](状态行扩展调研.md) | 想加素材/用时功能时的可行性实测:素材零拷贝引用(CSSOM / cloneNode)、用时三条 startTime 路线 |
