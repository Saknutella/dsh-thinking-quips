# dsh-thinking-quips

[English](README.md) · [中文](README.zh.md)

`v0.11.1` · **DSH bundle**（装上即用）· Web 客户端插件

**给 DeepSeek Harness 状态行做的轻量个性化** —— 就是智能体工作时会话里显示的那一行
（DSH 默认的 `Deep diving...`）。可轮换的中英俏皮话、十七种加载图标 × 三档尺寸、一键切换颜色预设、
达到 4.5:1 的一键匹配主题色，以及可选的用时显示，全部集中在 **设置 → 俏皮话**（设置导航里的独立一页，不再挤在「通用设置」下面）。

刻意的"增量"：零依赖、无构建、不写配置文件、不发网络请求。一个手写的客户端文件，
设置存在 `localStorage`，**不修改任何 DSH 自带包**。

![十七种加载图标 × 三档尺寸，配一条真实轮播俏皮话的状态行](assets/preview-gallery.png)

## 功能

- **十七种加载图标** —— 点阵环游（默认）、圆环旋转、形变环游、呼吸脉冲、三点跳动、柱状律动，
  外加**八个手绘 sprite**（来自两个设计家族：果冻块、节拍仔、敲敲仔、小风车、同心电波、进度珠、
  双星交替、带影子的弹弹球），以及三种直接复用 DSH 自带素材的：官方 `StateDot` 转圈、
  官方 logo 标志、以及**官方那条运行鲸鱼**（从实时状态行里 clone 出来，连动画一起），
  各有 **小 / 中 / 大** 三档。
  DSH 的鲸鱼是**可选项之一**、而不是永远并排的一只，所以状态行上永远只有一个指示图标；
  想要官方那只，选「官方鲸鱼（动态）」即可。
- **俏皮话轮播** —— 自己维护的列表，每行一条，用 `# Chinese` / `# English` 分段，在一个小弹窗里编辑；
  **语言**控件决定显示哪一段（跟随界面 / 仅英文 / 仅中文 / 混合）。
- **字体颜色** —— 预览色块、HEX、RGB，或原生颜色轮盘。
- **颜色预设** —— 品牌蓝、紫罗兰、青碧、琥珀、**彩虹**，各一键。每块色板都按**当前背景**实测调整、兜底到
  4.5:1，所以同一块色板在浅色与深色主题下都看得清；选中预设会同时停止「匹配主题色」的跟随
  （你已经点名了一个颜色）。其中「品牌蓝」写的是插件默认的哨兵值，因此它仍然等于 DSH 自己的默认色，
  而不是把默认色覆盖成一个固定值。**彩虹**让状态行（含图标）在六个颜色之间循环，而这六个颜色**每一个**都按
  当前背景拟合并兜底，所以循环的每一刻都守着这个承诺；色板本身保持**静态多彩**。速度跟随
  「慢 / 正常 / 快」，系统开启「减少动态效果」时冻结在第一个颜色。
- **扫光亮度** —— 0–100%，决定官方扫光那道流光比文字亮多少（0% 与文字同色＝看不出扫光，100% 纯白）。
  它写的是官方 `TextShimmer` 自己用来上色的 token，所以对官方扫光直接生效。
- **匹配主题色** —— 一键把当前主题的强调色适配到与当前背景**至少 4.5:1**，并持续跟随主题切换，直到你手动停止。
- **文字特效** —— **扫光**（默认，就是 DSH 官方那道流光：插件渲染官方 `TextShimmer` 组件）、
  **波浪**（每个字/每个词依次向上跳一下）。只有两项：自绘的「流光（旧版）」与官方扫光并排看没有区别，
  已随本次删除；旧配置里存的 `glow` / `official` 会自动落到扫光上。
- **用时显示** —— **随文**把用时并进俏皮话一起参与动画（DSH 0.2 的形式），**旁注**用灰色小字单独显示、
  不参与文字动画（0.1 的形式），也可以 **关闭**。用时取 DSH 官方的回合起始时刻（`turn.start.time`），
  口径与官方 `formatRunDuration` 逐字一致。
- **动画速度** —— **慢 / 正常 / 快** 一键切换。「正常」就是默认速度、不覆盖任何东西；另外两档缩放插件自己的动画。
  官方鲸鱼的动画是图片自带的 60 帧 APNG、帧率写在图片里，所以那一项改为在官方动画之外**加一个同步快慢的划水动作**。
- **每条显示时间**。
- **只显示加载图标** —— 只注入图标、不动状态文字，可与其他修改状态文字的插件共存。

## 安装

1. 把包装进 profile：
   ```sh
   dsh plugin --profile web add github:Saknutella/dsh-thinking-quips
   ```
2. 在 `$DSH_HOME/profiles/web/package.json` 的 `dsh.profile.bundles` 里加上它：
   ```json
   "dsh": { "profile": { "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-web-app", "dsh-thinking-quips"] } }
   ```
3. 重启 `dsh web`。

**要求**：DSH ≥ 0.2.0-rc.2（Web 界面）。0.2 的运行行是 `[data-chat-running]`，标签住在 DSH 的
`TextShimmer` 里；插件同时识别这种形状与旧的 `[class*="turnStatus"]`，所以 0.1.x 的老外壳也能跑。

**卸载**：从 `dsh.profile.bundles` 里移除，执行
`dsh plugin --profile web remove dsh-thinking-quips`，再重启 `dsh web`。
