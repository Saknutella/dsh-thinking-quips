# Loading 图标家族 · 两支小队

> 画给 14–20px 的小动画：圆润、微弹性、任天堂玩具感。
> 它们不是装饰画，是每秒都被盯着看的小等待者——动作小、有性格、不撒谎。
>
> - **家族一「小忙碌 Busy Bits」**（`svg/`，8 个）：全能日常款，节奏安静
> - **家族二「Q弹小队 Bouncy Pals」**（`svg-bouncy/`，6 个）：更可爱更俏皮，挤压拉伸感拉满

---

## 〇、两家族共用的统一规范（先读这个）

### 第 1 条：尺寸永远绑定字号（不满足即不合格）

- **盒子** = `1em × 1em`，即 **1 个字号（1 字高 h）见方**。SVG 根元素写 `width="1em" height="1em"`，不是 px。
- **内部坐标系**：`viewBox="0 0 24 24"`，即 **24 单位 = 1 字高 h**。换算：**1 单位 = 1/24 h ≈ 0.042h**。
- **所有形状、笔画、间距都用这 24 单位表达**，随字号天然等比缩放。
- **动画位移的 px 是"用户单位"**：SVG 内 CSS `transform: translateY(-3.6px)` 的 px 指 viewBox 单位（3.6 单位 = 0.15h），渲染时随整体缩放，**不会**变成固定像素。
- **自查**：把容器 `font-size` 在 14px ↔ 22px 之间来回改，图标整体等比缩放、比例不变。`index.html` 预览页已内置四档字号对照。

### 统一比例表（h = 字号 = 1 字高）

| 项 | 值（viewBox 单位） | 以字高表达 | 16px 时实际 |
|---|---|---|---|
| 盒子 | 24 × 24 | 1h × 1h | 16px |
| 笔画粗细 | 2.4 | **1/10 h** | 1.6px（清晰） |
| 最小圆点直径 | ≥ 3.2 | ≥ 2/15 h | ≥ 2.1px |
| 元素间缝 | ≥ 1.5 | ≥ 1/16 h | ≥ 1px |
| 常规位移幅度 | ≤ 3.6 | ≤ 0.15h | ≤ 2.4px |
| 弹跳类跳高（家族二） | ≤ 4.6 | ≤ 0.19h | ≤ 3px |

> 为什么笔画取 1/10 h 而不是 1/16 h：1/16 h 在 16px 下恰好 1px，抗锯齿后发虚；
> 1/10 h（16px 下 1.6px、22px 下 2.2px）全程实线可读，且视觉偏"圆润玩具感"，正合适。

### 统一节奏与动效纪律

| 项 | 家族规定 |
|---|---|
| 周期 | 全部 **1.6s**（两家族同一心跳，可混排不违和） |
| 缓动 | 位移/缩放/摆动：`cubic-bezier(.45,0,.55,1)`（easeInOutSine 近似）；旋转：`linear`（匀速是自然规律）；弹跳分段用 ease-in / ease-out 模拟重力 |
| 闪烁 | 全部图标最频繁处 ≤ 1.25 Hz（≤ 3 次/秒，光敏安全） |
| 减少动效 | 每个文件内嵌 `@media (prefers-reduced-motion: reduce)`，动画全部停止；**SVG 静态属性就是一张可读静帧**（个别元素如敲击火星、破掉的泡静态隐藏，见各档案"静帧"） |
| 动画属性 | 只用 `transform`（位移/旋转/缩放）与 `opacity`，无 JS、无 canvas、无 SMIL |
| 命名 | class / keyframes 带 `bb-`（家族一）/ `bq-`（家族二）前缀——内联进页面不污染全局，同页多实例不冲突 |
| 接缝 | 每个动画 100% 关键帧与 0% 关键帧状态完全一致（或经 opacity 掩护重置），肉眼无缝 |
| 缩放原点 | 凡"压扁/弹起"类，缩放原点必须锚在接触点（地面/柄底/球底），用外层 `translate()` 锚点法，不依赖 `transform-box`，兼容性最稳 |

### 用法

```html
<!-- 方式 A：<img> 引用（单文件即用，颜色跟随所在容器的 color） -->
<img class="loading-icon" src="svg-bouncy/03-bounce-ball.svg" alt="加载中">
<style>.loading-icon{vertical-align:-0.12em}</style>  <!-- 基线微调，按需 -->

<!-- 方式 B：内联 SVG 源码（换色最直接，currentColor 同样生效） -->
```

- 颜色：图形只用 `currentColor`（描边与填充同色），无渐变、无第二明度。深浅底都成立。
- 占位：盒子恒为 1em 见方，出现/消失不引起周围文字回流抖动。
- `width="1em"` 为 SVG2 几何属性，全现代浏览器支持；如需兼容极老内核，补 CSS：`.loading-icon{width:1em;height:1em}`。

## 一、家族一「小忙碌 Busy Bits」· 8 个档案

### 01 跳跳豆 · Hop Dots

- **比喻**：三颗小豆在原地排队跳格子，谁也不肯停。
- **什么在动**：三颗豆依次向上跳 3.6 单位（0.15h）再落回，相位差 60°，形成左→右的波浪。
- **关键帧与时长**：0→18% 升起，18→36% 落下，36→100% 静止待拍；1.6s；豆 2/3 用负延迟 -0.27s / -0.53s 进场。
- **尺寸表达**：豆直径 3.4 = **0.14 字高**；豆心距 7.2 = 0.3h（缝 0.16h）；跳高 0.15h。
- **16px 观感**：三颗小豆一个接一个地蹦，波浪感一眼可见。
- **最容易做坏**：豆间距 <3 单位会糊成一坨；用正延迟会让首拍前"全体静止一秒"，必须负延迟。
- **静帧**：三豆平排，本身就是一个"省略号"。

### 02 果冻块 · Jelly

- **比喻**：一块放在桌上的果冻，被谁轻轻按了一下，正在回弹。
- **什么在动**：圆角方块绕底部中心压扁（0.84× 高、1.08× 宽）→ 弹起 1.05× → 回正 → 0.98× 微呼吸。
- **关键帧与时长**：0→28% 压扁，28→42% 弹起过头，42→54% 回正，54→76% 微呼吸，76→100% 归位；1.6s。
- **尺寸表达**：方块 9.4 = **0.39 字高**见方，圆角 0.11h；形变 ±8~16%。
- **16px 观感**：一个小方墩在原地"duang"了一下，还带着余劲。
- **最容易做坏**：缩放原点不在底部——果冻会浮空压扁露馅；压扁低于 0.8 倍时圆角变形怪异。
- **静帧**：一块站得端端正正的圆角方块。

### 03 节拍仔 · Tick-Tock

- **比喻**：一支拿不定主意的节拍器，左想想、右想想。
- **什么在动**：梯形琴壳里，一根短臂绕**底部轴心**左右摆 ±42°——**轴在下面、杆在上面摆，这是节拍器**（钟摆是反过来：轴在上、锤在下摆）。
- **关键帧与时长**：0→50% 摆到右 42°，50→100% 摆回左 -42°；1.6s；ease-in-out；两端点即接缝。
- **尺寸表达**：臂长 8.4 = **0.35 字高**；摆幅 ±42°（端点横扫 ±0.23h）；琴壳宽 11.2 = 0.47h、高 0.31h。
- **16px 观感**：梯形小壳里一根指针慢悠悠地摆，"斟酌中"。
- **最容易做坏**：壳与杆在 16px 下线密，斜壁角度太陡会糊；摆太快变雨刷器喜剧过头。
- **静帧**：指针停在一侧的节拍器。

### 04 追豆仔 · Chomp

- **比喻**：一张张开合的大圆嘴，永远追不上前面那颗豆——像极了加载中的你。（吃豆人式构图：缺角圆在前，豆在后）
- **什么在动**：缺角圆身（嘴开口 ±45°，够大才一眼读懂）+ 前方一颗豆，**整体绕盒心顺时针匀速绕圈**；圆身自身 ±16° 开合（咀嚼），0.8s 一合一张。
- **关键帧与时长**：外圈 0→100% 转 360° linear 1.6s；咀嚼 0.8s（与外圈 2:1 锁相，整体仍无缝）。
- **尺寸表达**：身直径 13.6 = **0.57 字高**；豆直径 3.6 = 0.15h，缝 1.6 = 1/15 h。
- **16px 观感**：一个小圆嘴绕圈啃一颗够不着的豆。
- **最容易做坏**：嘴开太小（<±30°）在 16px 下读不出"嘴"；豆和嘴缝 <1.5 单位旋转中糊住；双层旋转原点必须都在圆心（锚点法）。
- **静帧**：嘴朝着豆摆好姿势，"准备吃"。

### 05 敲敲仔 · Bonk

- **比喻**：一根小木槌一下一下敲方块，每敲一下方块都被砸得矮一截再鼓回来。
- **什么在动**：45° 斜置的小棍从右上**敲下**（行程 0.083h）→ 回弹抬起；方块被敲中瞬间压扁（0.84× 高、1.12× 宽）→ 弹起 1.05× → 回正 → 待机微呼吸；**敲击瞬间方块顶两侧闪出两根小火星**（其余时间隐身）。
- **关键帧与时长**：棍 0→10% 敲下，10→20% 回弹，20→30% 归位；方块 10→16% 压扁 →26% 弹起 →36% 回正 →72% 起 0.99× 微呼吸；火星 opacity 12–20% 亮；1.6s。
- **尺寸表达**：棍长 7.8 = **0.33 字高**；方块 8 = 0.33h 见方；火星线长 2.83 = 0.12h；棍端与方块顶接触挤压 0.4 单位。
- **16px 观感**：笃、笃、笃——小锤敲方墩，火星一闪。
- **最容易做坏**：火星必须静态隐藏（opacity="0"）且只在敲中那一帧亮，常亮就成鬼图；方块缩放原点不在底部会穿到棍子下面；棍的位移必须是竖直下压（沿 45° 滑会滑离方块顶）。
- **静帧**：小棍悬停半空、方块端正、火星隐——"蓄势待敲"。

### 06 小风车 · Pinwheel

- **比喻**：窗台上一只纸风车，风一直没停。
- **什么在动**：三片圆角叶瓣 + 中心圆芯，整体**顺时针匀速**转。
- **关键帧与时长**：0→100% 旋转 360°，linear，1.6s。
- **尺寸表达**：整体外径 20 = **0.83 字高**；叶瓣 0.23h×0.35h，三瓣 120° 均布；芯直径 0.16h。
- **16px 观感**：一团会转的三叶小花，速度感比波浪更整。
- **最容易做坏**：叶瓣改尖角后 16px 下尖端消失；转速 <1.2s/圈看不出叶片轮廓。
- **静帧**：三叶花静止。

### 07 电波仔 · Ripple

- **比喻**：一颗小石子不断落进水里的涟漪，或天线在说"我在，我在"。
- **什么在动**：两圈圆环从中心长出（0.32×→1×）并向外**渐隐**，相位差半周期，永不断档。
- **关键帧与时长**：0→100% scale 0.32→1、opacity 1→0，linear，1.6s；第二圈延迟 -0.8s。
- **尺寸表达**：满圈直径 19.2 = **0.8 字高**；起始 0.26h 即可见；线宽恒 1/10 h。
- **16px 观感**：两个小圈交替从中心冒出来散开，安静但明显。
- **最容易做坏**：起始 scale <0.25 时中心圈小于 2px 刺眼；渐隐曲线设成 ease-out 会外圈拖尾发灰。
- **静帧**：两圈完整圆环（同心套圈）。

### 08 进度珠 · Bead-Run

- **比喻**：一颗珠子沿晾衣绳从这头跑到那头；跑完一颗，下一颗已经在左端站好。
- **什么在动**：珠子沿横线**从左到右**平移全程（0.43h），右端渐隐、左端静默重生。
- **关键帧与时长**：0→78% 平移全程，78→84% 右端渐隐，85% 瞬回左端（不可见），92→100% 左端淡入；1.6s。
- **尺寸表达**：线长 10.4 = **0.43 字高**；珠直径 4 = 0.17h（两家族最大圆点，它是主角）。
- **16px 观感**：一颗珠子匀速滑过短横线，逐项处理中的扫描感。
- **最容易做坏**：让珠子跑回去（往返）= 进度回退的谎言；重生必须 opacity 掩护，直接瞬移会跳帧。
- **静帧**：珠停在轨道左端。

## 二、家族二「Q弹小队 Bouncy Pals」· 6 个档案

> 挤压拉伸（squash & stretch）是这一家的母语。所有弹跳都遵守重力直觉：落下加速、弹起减速。

### 01 蘑菇弹弹 · Grow-Pop

- **比喻**：一颗蘑菇从地里探出头张望，挺一挺，又缩回去。
- **什么在动**：整株蘑菇绕**柄底贴地点**纵向伸缩：scaleY 0.06（缩在地里）→ 0.94 破土 → 1.05 回弹过冲 → 1 挺立 → 缩回。
- **关键帧与时长**：0% 地下 → 22% 破土 → 32% 回弹 → 42–72% 挺立 → 88% 缩回 → 100% 归位；1.6s。
- **尺寸表达**：伞直径 12 = **0.5 字高**；柄宽 3.6 = 0.15h；伸缩全程根点贴地不断开。
- **16px 观感**：一朵小蘑菇从地里嘣地长出来。
- **最容易做坏**：缩放原点不在柄底——蘑菇会"悬空缩"露馅；scaleY 压到 0 会让它整个闪没（留 0.06 当"根"）；宽高比不联动会像手风琴。
- **静帧**：立正蘑菇。

### 02 星光眨眨 · Sparkle-Swap

- **比喻**：草丛里两只萤火虫轮流眨眼。
- **什么在动**：大四角星绽放（scale 0.45→1）消散，小星隔半拍跟上，交替闪烁。
- **关键帧与时长**：星A 0→22% 绽放 →44% 消散；星B 相位 +50%；1.6s（每 0.8s 一次眨眼，1.25 Hz）。
- **尺寸表达**：大星直径 9.2 = **0.38 字高**；小星 0.62 倍；两星对角相距 ≥3 单位。
- **16px 观感**：一大一小两点星光此起彼伏地眨。
- **最容易做坏**：两星同时亮会挤成一坨；scale 与 opacity 必须同步（只闪不长 = 死板）；星用圆角内凹曲线，尖角直画在 16px 会秃。
- **静帧**：两颗星静态同框（大星 + 小星）。

### 03 弹弹球 · Bounce-Ball

- **比喻**：一只看不见的手在原地拍皮球，啪嗒、啪嗒。
- **什么在动**：球下落（加速）→ 落地压扁（1.2× 宽、0.76× 高）→ 弹起拉伸（0.9× 宽、1.1× 高）→ 回到最高点；影子同步变宽变窄表达高度。
- **关键帧与时长**：0→34% 下落 ease-in →42% 压扁 →60% 空中拉伸 ease-out →82% 回顶点；影 scaleX 0.68↔1 同相位；1.6s。
- **尺寸表达**：球直径 6.8 = **0.28 字高**；跳高 4.6 = 0.19h；影 5.4×2.1；球底与影间缝恒 ≥1.75 单位。
- **16px 观感**：小球啪嗒啪嗒地弹，影子一收一放。
- **最容易做坏**：压扁原点不在球底会穿进影子里；影子不变宽窄 = 球像在"平移"而非"跳"；下落不加速就不像皮球像幽灵。
- **静帧**：球定格在半空 + 窄影，一个跳跃瞬间。

### 04 摇摆花 · Wobble-Flower

- **比喻**：一朵小花在风里摇头晃脑。
- **什么在动**：整朵花绕**茎底**左右摇摆 ±13°，ease-in-out 悠回来悠过去。
- **关键帧与时长**：0→50% 摆右 13° →100% 摆回左 -13°；1.6s。
- **尺寸表达**：花径 15 = **0.63 字高**（家族二最大主体）；茎长 10 = 0.42h；摆轴横偏 ≤0.17h。
- **16px 观感**：小花在原地摇头，心情很好的样子。
- **最容易做坏**：摆轴设在花心就成了"拔苗式"平移——必须在茎底；幅度 >16° 看着像要折断。
- **静帧**：直立小花。

### 05 吹泡泡 · Bubble-Blow

- **比喻**：圆头小孩吹泡泡，泡越吹越大，"啪"破了，把自己吓一哆嗦。
- **什么在动**：空心泡从头边长出（scale 0.3→1）→ 贴到头边鼓一下（1.05×）→ 破（opacity 瞬隐）；头在破的瞬间 squash 抖一下再回正。
- **关键帧与时长**：泡 0→8% 冒头 →50% 长满贴头 →55% 鼓 →58% 破；头 56→82% 惊吓 squash →90% 微呼吸；1.6s（破 1 次/循环 = 0.625 Hz）。
- **尺寸表达**：头直径 10 = **0.42 字高**；泡满径 6.8 = 0.28h；泡小的时候与头缝 2.5，长大到恰好相切（吹出感）。
- **16px 观感**：吹——啪——抖，一气呵成。
- **最容易做坏**：泡破时头不抖，就只是"一个圈消失"；破的 opacity 突变每循环只许一次；泡若画成实心 fill 会和头粘成一坨，必须空心描边。
- **静帧**：头 + 一个吹满的泡。

### 06 心心脉冲 · Heart-Pulse

- **比喻**：小心心"咚·哒"两连跳，然后安静半拍。
- **什么在动**：心绕自身中心 scale 1→1.15（咚）→1→1.07（哒）→1，后 54% 静止休息。
- **关键帧与时长**：0→12% 咚 →24% 回 →34% 哒 →46% 回 →100% 静；1.6s（两峰 = 1.25 Hz）。
- **尺寸表达**：心宽 9.4 = **0.39 字高**、高 8.7 = 0.36h；峰值位移 0.03h/边，克制。
- **16px 观感**：一颗小心心有节律地跳。
- **最容易做坏**：两峰间隔 <8% 会糊成一次抖动；幅度 >1.2 像抽搐；心形两圆与三角必须重叠无隙，否则轮廓有豁口。
- **静帧**：一颗安静的心。
